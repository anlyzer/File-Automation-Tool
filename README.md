# File Automation Tool (Python)

This project is a Python-based File Automation Tool that automatically organizes files in a folder based on their file types.

## 📌 Project Objective
To reduce manual effort in organizing files by automatically scanning a folder and sorting files into categorized directories.

## features :-
Build a Python script that automatically organizes files in a folder.

● Scan a selected directory
● Automatically sort files by type (images, documents, videos, PDFs, etc.)
● Move them into categorized folders
● Log all actions in a log file

## 🛠 Technologies Used
- Python
- os module
- shutil module
- datetime module

## 📂 Project Files
- `file_automation.py` – Core automation script
- `README.md` – Project documentation

> Users can select any folder on their system to organize files.
